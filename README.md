# Contract Auto-Redline

An AI-powered contract analysis, risk rating, automated redlining, deadline extraction, and negotiation email generation platform designed for freelancers, indie hackers, and developers.

## Project Structure

```
├── Frontend/      # Next.js 15, Tailwind CSS, TypeScript, Supabase Auth & UI
└── Backend/       # Backend analysis pipelines and APIs
```

## Tech Stack
- **Frontend**: Next.js (App Router), React 19, TypeScript, Tailwind CSS, Lucide Icons
- **Database & Auth**: Supabase (PostgreSQL, Row Level Security)
- **AI**: Google Gemini API
